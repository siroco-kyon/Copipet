# コピペット 仕様書

## 1. 目的
メールやチャットでよく使う定型文をボタンに登録し、ワンクリックでクリップボードへコピーして入力の手間を減らす。

## 2. 動作環境と軽さの方針
- .NET Framework 4.8 / WinForms。Windows 10・11 に標準搭載のためランタイムのインストールは不要
- exe1つで動作し、外部DLLは使わない（JSONは標準の `DataContractJsonSerializer`）
- 起動時の処理は data.json を1回読むことだけ。通信・常駐・常時動くタイマーはない
- 二重起動しない。2つ目を起動すると、開いているウィンドウを前面に出して終了する（保存内容の上書き防止）

## 3. 画面

### 3.1 トップ画面
- レイアウトは ⚙ メニューで切り替える（初期値は2列）

  | | 2列（横長） | 1列（縦長・幅が狭い） |
  |---|---|---|
  | 画面の大きさ（100%表示） | 約 470×380 | 約 272×620 |
  | タブ | 4つ×2段 | 2つ×4段 |
  | コピーボタン | 2列。左→右、上→下の順（5段ぶん表示） | 1列。上から順（10段ぶん表示） |

- 上部：タブ（最大8つ）。タブが8つ未満のときは次の位置に「＋」を表示。タブ欄の高さは最大数ぶん確保し、タブを増やしても画面の大きさは変わらない
- 中央：コピーボタン（1タブ0〜20件）と、末尾に「＋ 追加」。表示しきれない分はボタン欄だけが縦にスクロールし、タブと下部は常に見える
- 20件に達すると「＋ 追加」は消える。件数が0のタブには「＋ 追加（最初の1件を登録）」だけを表示
- 下部：状態表示欄（コピー結果を2秒表示）と ⚙ ボタン
- 最大化・最小化ボタンなし、サイズ固定、画面中央に表示
- 起動時は前回最後に選んでいたタブを表示

### 3.2 コピー内容の編集画面
- タイトル（1行、30文字まで）、内容（複数行、縦スクロール）
- 「保存」「戻る」。`Ctrl+S` で保存、`Esc` で戻る（確認なしで破棄）
- タイトルバーに「コピー内容の編集 - タブ名 No.n」と表示

### 3.3 タブ名の変更画面
- タブ名（8文字まで）、「保存」「戻る」。`Enter`／`Ctrl+S` で保存、`Esc` で戻る
- 空欄で保存すると「タブn」（n は位置）になる

## 4. 操作
| 操作 | 動作 |
|---|---|
| コピーボタン左クリック | 内容をコピー。未登録なら編集画面を開く |
| コピーボタン右クリック | メニュー：編集（太字）／前へ移動／後ろへ移動／削除（1列では「上へ」「下へ」と表示） |
| ＋ 追加 | 末尾に1件追加して編集画面を開く。戻る、または空のまま保存したら追加しない |
| コピーボタンにマウスを乗せる | 内容の先頭100文字をツールチップ表示（未登録は「クリックして登録」） |
| タブ左クリック | 表示切替（ボタン欄のスクロール位置は先頭に戻す） |
| タブ右クリック | メニュー：名前を変更／左へ移動／右へ移動／削除 |
| ＋ | 「タブn」の名前でタブを追加し、そのタブを表示 |
| ⚙ | テーマ（Windowsの設定に合わせる／ライト／ダーク）、レイアウト（2列／1列）、常に最前面に表示、データフォルダを開く |

- 端のタブでは該当方向の移動を無効化。タブが1つのときは削除を無効化
- 削除時は確認する。登録済みがあれば「登録済みの n 件も消えます」と表示
- 選択中のタブを移動すると、選択も一緒に移動する
- コピーボタンの削除は、タイトルか内容が入っていれば確認する。先頭・末尾では該当方向の移動を無効化

## 5. 表示ルール
- 未登録（内容が空）のボタンは灰色文字で「（未登録）」。タイトルだけ入っている場合はタイトルを灰色で表示
- 内容があってタイトルが空のときは「（無題）」
- 長いタイトル・タブ名は末尾を「…」で省略

## 6. データ
- 保存先：`%APPDATA%\Copipet\data.json`（UTF-8、BOMなし、整形済み）
- 構造：
  ```json
  {
    "version": 1,
    "lastTab": 0,
    "theme": "auto",
    "topMost": false,
    "layout": "two",
    "tabs": [
      { "name": "メール", "items": [ { "title": "お疲れ様です", "content": "お疲れ様です。\r\n○○です。" }, ... 0〜20件 ] }
    ]
  }
  ```
- 保存：一時ファイル（.tmp）に書いてから差し替え、直前の版を `data.json.bak` に残す。差し替えが使えない環境ではコピーで代替
- 保存のタイミング：登録・タブ操作・設定変更のたび。最後に選んだタブは終了時に保存
- 読み込み時の補正：タブ数を1〜8、各タブ20件までに切り詰め、末尾に並ぶ「タイトルも内容も空」の項目は詰める（途中の空きは残す。旧版の10件固定データもこれで移行される）。タイトル30文字・タブ名8文字を超える分は切り詰め。不明なテーマは auto、不明なレイアウトは two
- 破損時：`data.json.broken_日時` に退避し、`.bak` が読めればそこから復元、読めなければ空の状態で起動し、起動後に知らせる
- 本体がなく `.bak` だけある場合は `.bak` から復元
- 初回起動：フォルダとファイルを作成し、「タブ1〜3」の3タブ（各0件）で開始

## 7. クリップボード
- テキスト（Unicode）のみ。改行は CRLF に揃える
- 他のアプリが使用中で失敗した場合、100ms 間隔で5回まで再試行。失敗したら状態表示欄に表示

## 8. テーマ
| 部分 | ライト | ダーク |
|---|---|---|
| 背景 | #F5F5F5 | #1E1E1E |
| コピーボタン | 白／黒文字 | #2D2D30／白文字 |
| 選択中タブ | DeepSkyBlue／黒文字（太字） | #1E90FF／白文字（太字） |
| 非選択タブ | DarkGray／黒文字 | #3C3C3C／#DDDDDD |
| 入力欄 | 白 | #252526 |

- タイトルバー：DWM の属性でダーク化（Windows 10 1809 以降。古い版はライトのまま）
- スクロールバー：`DarkMode_Explorer` テーマを適用
- 右クリックメニュー・⚙メニュー・ツールチップ：自前で描画
- 確認ダイアログ（MessageBox）は Windows 標準のまま
- 「Windowsの設定に合わせる」は起動時とテーマ選択時にレジストリ（AppsUseLightTheme）を読む

## 9. 高DPI
- システムDPI対応（マニフェスト）。部品の配置は 100% 表示時の値に画面の拡大率を掛けて計算する

## 10. 対象外
常駐・ホットキー、画像やファイルのコピー、1タブ21件以上、データの暗号化、複数PC間の同期
