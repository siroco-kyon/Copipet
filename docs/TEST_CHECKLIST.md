# コピペット テストチェックリスト

Windows 上で確認してください。✅ を付けながら進められます。
事前に `%APPDATA%\Copipet` を削除（または名前変更）しておくと、初回起動から確認できます。

## 1. 起動
- [ ] 1-1 初回起動で「タブ1〜3」が表示され、ボタン欄には「＋ 追加（最初の1件を登録）」だけがある
- [ ] 1-2 `%APPDATA%\Copipet\data.json` が作られている
- [ ] 1-3 画面が中央に表示され、最大化・最小化ボタンがなく、サイズを変えられない
- [ ] 1-4 タスクバーとウィンドウ左上に吹き出しアイコンが出ている
- [ ] 1-5 起動中にもう一度 exe を起動すると、新しい画面は開かず、既存の画面が前に出る

## 2. コピー内容の登録・並べ替え
- [ ] 2-1 「＋ 追加」→ 編集画面が開き、タイトルと内容を入れて「保存」→ ボタンが増える
- [ ] 2-2 「＋ 追加」→「戻る」（または空のまま保存）→ ボタンは増えない
- [ ] 2-3 コピーボタンを右クリック → メニュー（編集／前へ移動／後ろへ移動／削除）が出る。「編集」で編集画面が開き、タイトルバーに「タブ名 No.n」
- [ ] 2-4 編集画面で `Ctrl+S` でも保存できる。内容を変えて「戻る」または `Esc` → 変更されていない
- [ ] 2-5 タイトルに31文字以上入力できない。タイトルを空にして内容だけ保存 → 「（無題）」
- [ ] 2-6 内容を空にして保存 → 灰色表示になり、左クリックで編集画面が開く
- [ ] 2-7 「前へ移動」「後ろへ移動」で並びが変わる。先頭では「前へ」、末尾では「後ろへ」が押せない
- [ ] 2-8 「削除」で確認が出て、「はい」で消える。「いいえ」で何も起きない
- [ ] 2-9 1タブに20件まで追加でき、20件になると「＋ 追加」が消える。1件削除すると再び出る
- [ ] 2-10 2列で11件以上、1列で10件以上になると、ボタン欄だけに縦スクロールバーが出る。タブと ⚙ は隠れない。ボタンとスクロールバーが重ならない
- [ ] 2-11 マウスホイールでボタン欄がスクロールする
- [ ] 2-12 別のタブに切り替えると、ボタン欄は先頭から表示される
- [ ] 2-13 全タブに登録し、タブを切り替えても正しい内容が表示される

## 3. コピー
- [ ] 3-1 登録済みボタンを左クリック → メモ帳に貼り付けて内容が一致する（改行を含む文章も）
- [ ] 3-2 画面下に「コピーしました：タイトル」が出て、約2秒で消える
- [ ] 3-3 Outlook・Teams にも貼り付けられる
- [ ] 3-4 ボタンにマウスを乗せると内容のプレビューが出る（100文字を超えると「…」）
- [ ] 3-5 全タブの全登録ボタンでコピー内容が正しい

## 4. タブ
- [ ] 4-1 タブを左クリックで切り替わり、選択中のタブが青色（太字）になる
- [ ] 4-2 「＋」でタブが増え、追加したタブが選択される。8つになると「＋」が消える
- [ ] 4-3 タブ右クリック →「名前を変更」で変更できる。9文字以上は入力できない。空欄で保存すると「タブn」
- [ ] 4-4 「左へ移動」「右へ移動」で並びが変わり、中身も一緒に動く。端のタブでは該当の移動が押せない
- [ ] 4-5 タブの「削除」で確認が出る。登録がある場合は件数が表示される。「いいえ」で何も起きない
- [ ] 4-6 タブが1つのときは「削除」が押せない
- [ ] 4-7 終了して再起動すると、最後に選んでいたタブが表示される

## 5. テーマ・設定
- [ ] 5-1 ⚙ → テーマ → ダーク：背景・ボタン・タブ・タイトルバー・メニューが暗くなる
- [ ] 5-2 ダークで編集画面を開く：入力欄・スクロールバー・タイトルバーが暗い
- [ ] 5-3 ⚙ → テーマ → ライト：元に戻る
- [ ] 5-4 「Windowsの設定に合わせる」：Windows の設定（個人用設定 → 色 → アプリモード）に従う
- [ ] 5-5 ⚙ →「常に最前面に表示」をONにすると、他のウィンドウの上に出続ける。OFFで解除
- [ ] 5-6 ⚙ → レイアウト →「1列」：幅が狭くなり、ボタンが上から順に縦1列、タブが2つ×4段になる。右クリックメニューの移動が「上へ」「下へ」になる
- [ ] 5-7 1列でもコピー・編集・タブ操作がすべて使える。「2列」に戻すと元の配置になる
- [ ] 5-8 レイアウトを切り替えても画面の外にはみ出さない
- [ ] 5-9 テーマ・レイアウト・最前面の設定が再起動後も保たれる
- [ ] 5-10 ⚙ →「データフォルダを開く」でエクスプローラーが開く

## 6. データの安全性
- [ ] 6-1 保存を2回以上すると `data.json.bak` ができる
- [ ] 6-2 終了して `data.json` をメモ帳で開き、中身を壊して（例：先頭の `{` を消す）保存 → 起動すると「1つ前の保存内容から復元しました」と出て、直前の内容で起動する。`data.json.broken_日時` が残っている
- [ ] 6-3 `data.json` と `.bak` の両方を壊す → 「空の状態で起動しました」と出て起動する
- [ ] 6-4 exe を別のフォルダ（デスクトップなど）へ移動して起動 → 登録内容がそのまま表示される
- [ ] 6-5 `%APPDATA%\Copipet` を別のPCへコピー → 同じ内容で起動する
- [ ] 6-6 旧版（1タブ10件固定）の data.json で起動 → 登録済みの項目はそのまま、末尾の空きは詰められて表示される

## 7. 表示
- [ ] 7-1 長いタイトル・タブ名が「…」で省略され、はみ出さない
- [ ] 7-2 Windows の表示スケール 125%・150% でも文字がにじまず、2列・1列どちらもレイアウトが崩れない
